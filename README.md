# Аналитика по наставникам

Веб-приложение по [PRD.md](PRD.md): загружаете Excel-файл со стажёрами — получаете таблицу «Аналитика по Наставникам» по месяцам и кварталам и скачиваете её в Excel.

Файл обрабатывается **только в браузере** и никуда не отправляется. В браузере (localStorage) сохраняются только решения по ФИО и месяцам групп.

## Как пользоваться

1. Откройте `dist/index.html` двойным щелчком (Chrome, Edge, Firefox). Сервер не нужен — это один файл, его можно скопировать коллегам.
2. Перетащите файл Excel в окно.
3. Вкладка **«Проверка ФИО»**: ответьте на вопросы «один человек / разные люди» и про спорные ячейки. Счётчик нерешённых случаев — вверху справа.
4. Вкладка **«Группы»**: при необходимости поменяйте месяц учёта группы (например, группа от 31.03 → апрель).
5. Нажмите **«Скачать Excel»**.

Решения можно сохранить в файл и передать коллеге («Проверка ФИО» → «Принятые решения»).

### Правила подсчёта (раздел 6 PRD)

- **На входе**: стажёр даёт +1 каждому наставнику, у которого был хотя бы один день практики (один раз, независимо от числа дней).
- **Сдали**: +1 каждому наставнику стажёра с результатом «Сдал».
- **Месяц** — по дате старта группы, можно изменить вручную.
- Стажёр без наставника ни одному наставнику не засчитывается.

### Склейка ФИО (раздел 7 PRD)

- Совпадающие после нормализации (регистр, казахские буквы, удвоенные буквы, порядок слов) — склеиваются всегда.
- Похожие фамилия и имя (≥ 85 %) **в одной ЛС** — склеиваются автоматически, это можно отменить («Отделить»).
- Похожие с меньшей уверенностью или в разных ЛС — вопрос пользователю; пока ответа нет, считаются разными людьми.
- Варианты, совпавшие с разными людьми из реестра, никогда не склеиваются между собой.

## Что проверить на реальном файле (раздел 10 PRD)

Реального файла в проекте нет, поэтому приёмка по цифрам из раздела 10 (490 стажёров, 406 с наставником, ≈260 наставников, «на входе» по месяцам, Касымкулова Жанар — 4 в апреле и т. д.) ещё не проводилась. После загрузки файла сравните эти цифры с карточками вверху экрана и таблицей; при расхождениях загляните во вкладку «Проверка ФИО».

Открытые вопросы PRD (раздел 11) решены так:
1. Правило «на входе» — один день = пять дней, как в PRD.
2. Группы на стыке месяцев — по дате старта, с ручным выбором.
4. Наставники из реестра без стажёров — показаны списком во вкладке «Проверка ФИО».
5. Решения хранятся у пользователя, обмен — через файл решений.
